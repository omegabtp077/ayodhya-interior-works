## Customization Guide

### Update Contact Information
Edit `index.html` and replace:
- Phone number: `+91-XXXX-XXXX-XX`
- Email: `info@ayodhyainteriorworks.com`
- Address: Update the map location
- WhatsApp link: Update the phone number in WhatsApp URL

### Add Your Projects
Replace placeholder images in the Portfolio section with your actual project photos:
```html
<img src="https://via.placeholder.com/300x250?text=Bedroom+Renovation" alt="Bedroom">
```

### Update Business Details
Modify the About section statistics:
- Number of customers
- Years of experience
- Satisfaction rate

### Add Social Media Links
Update the footer social links with your actual profiles:
```html
<a href="https://facebook.com/yourpage"><i class="fab fa-facebook"></i></a>
```
